# Копирование и экспорт недель — 17.10.2026

## Что исправлено

1. «Массовые операции с неделями» → «Копировать все группы» теперь формирует точный снимок исходной недели. В отличие от прежнего варианта, занятия не создаются заново исключительно по шаблону графика целевой недели: сохраняются явные изменения формата (в том числе ДО), преподавателей, подгрупп, потоков, дня, пары, комнат и половинных пар.
2. Требования, которые присутствуют только в графике целевой недели, сохраняются в «Не размещено». Ручные занятия исходной недели, отсутствующие в графике целевой недели, остаются частью снимка, а не удаляются.
3. Расстановка целевой недели заменяется одним атомарным действием. Остальные недели, однократные мероприятия и данные публикации не затрагиваются; после изменения нужна отдельная публикация.
4. В раскрываемом разделе «Массовые операции с неделями» добавлена отдельная строка **«Выгрузить неделю» → «Экспорт недели в Excel — все группы»**. Выгрузка не зависит от активного просмотра и создаёт Excel с листом каждой группы. Включена колонка «№ пары» для нестандартного времени звонков; дистанционные занятия отмечены «ДО».
5. Импорт такого Excel понимает явный номер пары и сохраняет дистанционный формат занятия из столбца «Аудитория» (ДО).

## Примечания

- Excel экспортирует **расстановку**, а не историю разовых замен. Журнал замен ведётся отдельно.
- При импорте Excel сохраняется прежняя проверка соответствия текущему графику/нагрузке. Поэтому ручные занятия вне графика могут быть отклонены. Для точного копирования вне графика пользуйтесь кнопкой «Копировать все группы».
- Для безопасного развертывания сначала сохраните резервную копию базы и проверьте операции на тестовом контуре. React сборка в этой среде не запускалась из-за отсутствующих npm-зависимостей.
