# Переносы импортированных отменённых занятий (18.10.2026)

- В разделе «Замены» импортированные отмены без связи с `schedule.instances` теперь можно назначать на новую дату/пару: группа, преподаватель, дисциплина, формат, кабинет, длительность.
- До назначения они не считаются проведёнными; после назначения сохраняются как запись `type: moved` с исходной и целевой датой. Для записей без исходной сетки строится виртуальная ячейка переноса для отображения на выбранной дате, без изменения исходной нагрузки.
- Проверяются конфликты группы, преподавателя и кабинета, с предупреждением при совпадении.
- Повторный импорт Excel дополняет недостающие названия у ранее сохранённых записей с тем же ID, без удаления замен и без создания дублей.
- Отчёт фактических часов включает назначенные импортированные переносы по целевой дате, неподтверждённые остаются в разделе сверки.

## Внимание перед установкой

Сначала сделайте резервную копию БД и проверьте изменения на тестовой копии. Для восстановления ранее пустых полей повторно импортируйте тот же Excel-файл и сохраните изменения. Исходные записи с отсутствующим ID преподавателя или группы требуют ручного выбора при назначении переноса. Запись назначенного переноса не подтверждает факт проведения автоматически; для строгого табеля требуется контроль проведения.

Полная фронтенд-сборка недоступна в окружении (нет зависимостей node_modules и доступа к npm registry). Нужны сборка и проверка на реальной тестовой базе перед продакшеном.
