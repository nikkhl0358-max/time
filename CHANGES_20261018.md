# Обновление 18.10.2026

- Обновлён внешний вид кнопки обновления и отдельных элементов публичной страницы.
- В расписании преподавателя названия групп становятся переходами к расписанию группы; обратный переход к преподавателю сохранён.
- Выгрузка всех преподавателей приведена к формату примера: один лист на преподавателя, заголовок, период, 5 колонок.
- В разделе кабинетов добавлена проверка занятости выбранного кабинета по конкретному дню и паре в пределах загруженной опубликованной недели.
- В разделе «Замены» можно сохранить отменённую пару с названием дисциплины, группой, преподавателем и примечанием; отдельно отображаются импортированные записи без связи с сеткой.
- Добавлена предварительная выгрузка часов преподавателей за диапазон дат. Расчёт по сетке учитывает отменённые занятия и смену преподавателя, но НЕ является итоговым табелем: переносы, практики, занятия вне сетки и подтверждение фактического проведения нужно доработать и сверить.

## Важно

Ручные записи отмены без связи с ID занятия сохраняются в журнале, но не меняют сетку, не резервируют аудиторию и не учитываются в часах. Связывание таких записей с расписанием и полноценный импорт названий из произвольных Excel-файлов ещё не реализованы. Экспорт реализован по структуре образца, без гарантии пиксельного совпадения оформления.

JSX проверен TypeScript transpileModule (ошибок синтаксиса нет). Полная сборка Vite и интеграционные тесты не выполнены: зависимости npm в среде отсутствуют, установка не завершилась. Перед развёртыванием выполните `cd frontend && npm ci && npm run build` и проверьте страницу на тестовом сервере.
