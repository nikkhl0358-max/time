# Исправление отменённых пар у преподавателей

В frontend/src/App.jsx устранён ранний `return null` в публичном календаре для всех `excursion` вне режима группы. Теперь только группа получает карточку мероприятия «Экскурсия», а преподаватель проходит в общий блок отмены занятия, где сохраняются предмет, группа и зачёркивание красным.

Обновить запущенное приложение из этого архива и перепубликовать соответствующую неделю при необходимости. Изменение исходных данных и базы не требуется.
