# Экскурсия в заменах (21.10.2026)

Вкладка «Замены / отмены / переносы» → дата → нужная группа и пара → «Заменить» → «🚌 Экскурсия». Изменение создаётся отдельно для каждой пары/группы, без назначения аудитории. При необходимости «Изменить» позволяет указать место/название экскурсии. Для отмены операции — крестик. Для отображения у студентов опубликуйте замены выбранного дня.

Исходная нагрузка и постоянное расписание не изменяются. Экскурсия отмечена отдельным типом `excursion`, не занимает аудиторию и не считается проведённой учебной парой в отчёте фактических часов. Обратите внимание: группы, объединённые в одном экземпляре потокового занятия, по-прежнему редактируются вместе; чтобы назначить экскурсию только одной группе из такого потока, сначала требуется разделить поток.
