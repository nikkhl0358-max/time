# Исправление неполного JSON при входе (6 ноября 2026)

Симптом: после отправки формы входа браузер отображал `Failed to execute 'json' on 'Response': Unexpected end of JSON input`.

## Исправлено

- `frontend/src/editorTransport.js`: GET-запросы к API редактора при пустом/обрезанном JSON, сетевом обрыве и временных 502/503/504 (также 408/425/429/500) автоматически повторяются до 3 попыток с коротким ожиданием.
- При постоянном сбое ошибка указывает точный URL и HTTP-статус. Ответы 401/403/409 не повторяются.
- POST-запросы авторизации и сохранения не повторяются, чтобы избежать повторных операций.
- `tests/regression/test_editor_response_recovery.mjs`: тесты обрыва JSON, пустого ответа, 502, отказа доступа и постоянного сбоя.
- `tools/check_editor_client.mjs`: тестовый fetch дополнен реалистичным `text()` для работы с обработчиком ответов.

## Безопасность и производительность

При корректном ответе добавочных запросов и ожиданий нет. Изменения не затрагивают структуру проекта, расписание, алгоритмы поиска, сохранение или структуру БД. Повторные запросы происходят только при ошибке чтения.

## Важно

Это устранение неустойчивости клиента и улучшение диагностики, а не доказанное устранение серверной причины обрыва. При повторе ошибки проверьте Network для `/api/auth/login` и `/api/editor/schedule-data-v2?section=bootstrap`, вкладку Response и логи контейнера (ошибки OOM, gunicorn worker timeout, исключения Python). Не присылайте пароль или session cookie.

Тесты: `python tests/run_regression.py` — 24/24 пройдено локально.
