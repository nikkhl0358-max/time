# Исправление импорта Excel-графиков (v3)

В разделе «Графики» кнопка «Загрузить Excel (включая заблокированные)»:
- сопоставляет строки по точному ID нагрузки;
- для строк без ID использует группу, дисциплину, преподавателя, вид занятия и подгруппу, пропуская неоднозначные совпадения;
- по явному подтверждению заменяет недельные значения даже в заблокированных строках, не снимая блокировки;
- проверяет отрицательные значения, шаг 0,5 пары, дубликаты строк;
- показывает отчёт о количестве обновлённых/пропущенных строк.

ВАЖНО: технические restore7_load_* нагрузки не удаляются, занятия не изменяются. Для устранения технических дублей требуется отдельная проверка связей. Перед импортом обязательно резервная копия БД. Полная сборка frontend в этой среде не выполнена; сначала деплой на тестовом приложении.
