# Проверка 9-й недели перед исправлением

Добавлен read-only аудит `tools/audit_week9.py`. Он проверяет выгрузку PostgreSQL без доступа на запись и отделяет технические копии `EXACT` от требований графика `GRAPH_ONLY`.

Запуск:

```bash
python3 tools/audit_week9.py /path/to/timeweb_week9_diagnostics_20261019.json.gz --output week9_audit.json
```

Результат по присланной выгрузке: 1394 экземпляра, явно ограниченных неделей 9; 1062 GRAPH_ONLY, 292 EXACT; из них назначены 22. Проверка полной семантической идентичности (участники потока, loadId, слой, половинная пара, формат, преподаватель, предмет и вид занятия) **не нашла точных совпадений** внутри этих 1394 записей. Это не исключает ошибку привязки к recurring-занятиям или графику, но исключает безопасное массовое удаление по одному только суффиксу ID.

Скрипт НИЧЕГО не изменяет. Удаление или перепривязка требуют анализа общего графика и архивных/повторяющихся экземпляров, чтобы не потерять реальные часы и разные подгруппы.
