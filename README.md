# КТМУ — расписание с двумя вариантами оформления

Проект основан на `time-main (5).zip`, с новым публичным дизайном из `timetable22-main(1).zip`.

## Переключение

В правом нижнем углу всех страниц есть переключатель **Дизайн: Старый / Новый**.
- **Старый** — исходный интерфейс React из первого проекта, включая административные страницы.
- **Новый** — современный публичный интерфейс Vue; на `/admin` остаётся прежний функциональный React-редактор с новой CSS-темой.
- Выбор сохраняется в `localStorage` браузера (`ktmu-design-version`). Для применения интерфейс перезагружается.
- На другом устройстве выбор задаётся отдельно. По умолчанию открывается новый дизайн.

## Установка/развёртывание

Загружайте содержимое папки `time-main` (не по одному файлу вручную, если платформа поддерживает ZIP/Git). Архив содержит меньше 100 исходных файлов. Сборка происходит в Dockerfile: `npm ci` и `npm run build` для фронтенда, затем Flask/Gunicorn.

Локальная сборка: `bash build.sh` (требует интернет-доступа к npm при первой установке).

Из облегчённого архива убраны старые отчёты, тесты, диагностические утилиты и дублирующая папка `tools`; основной сервер, зависимости, Dockerfile, исходники обеих версий фронтенда и миграционный скрипт сохранены.

Примечание: полноценная npm-сборка не запускалась в изолированной среде подготовки, поскольку пакет `xlsx-js-style` отсутствует в офлайн-кэше. Для развёртывания нужна доступность npm registry.
