# Просмотр занятости всех кабинетов

На публичной вкладке «Кабинеты» добавлен раскрывающийся блок «Посмотреть свободные и занятые кабинеты».

1. Выберите неделю с помощью стрелок в расписании, затем дату и номер пары в блоке.
2. Сервис запрашивает `/api/public-room-availability?date=YYYY-MM-DD&period=0`.
3. Показываются две колонки: «Свободно» и «Занято», в занятых — группа, предмет, преподаватель.
4. Нажатие на кабинет открывает существующее персональное расписание кабинета.

Расчёт производится **из опубликованного снимка**, а не из рабочего черновика. Учтены регулярные пары, отмены, замены кабинета, целевые даты переносов, пересдачи и промежуточные аттестации. Проверка проводится в рамках выбранного семестра и опубликованных недель.

Важно: резервирования аудиторий практикой, не представленные в обычной сетке или отдельных записях аттестаций, пока не входят в сводный расчёт. При необходимости можно расширить проверку на эту разновидность бронирования.

Проверка: `python -m py_compile app.py` выполнена. Полную сборку фронтенда выполнить нельзя без установленных зависимостей `node_modules` (команда `npm run build` требует `vite`). Перед установкой на продакшен проверьте на тестовом окружении.
