# Проверка расхождений 9-й недели

В меню «Массовые операции с неделями» выберите 9-ю неделю и нажмите «Показать расхождения с графиком».

- Выводятся исходные записи для требований с превышением, включая группу, предмет, преподавателя, происхождение и назначение.
- Занятия, уже размещённые в расписании, не допускаются к удалению через эту форму.
- К выбору доступны только единичные неназначенные технические экземпляры целевой недели без потоков/многонедельных связей.
- Выбор и удаление исключительно ручные. Перед сохранением вызывается серверная резервная копия.
- Нет автоматической перепривязки к графику. Ноль по графику не трактуется как доказательство лишней пары.
- Без сопоставления с живой БД и проверки на тестовой копии применение на рабочем сервере не рекомендуется.

## Проверка
- `python -m py_compile app.py` выполнено.
- Полная сборка Vite не подтверждена: npm install зависает в этой среде.
