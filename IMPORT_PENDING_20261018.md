# Импорт отмен и замен без ID записи

- Поддерживается XLSX с колонками «Дата», «Группа», «Предмет», «Тип изменения» и дополнительными полями. ID записи не обязателен.
- Если есть лист «Все изменения», читается только он (иначе одно и то же может повторяться на листах источников).
- Для строк без ID формируется стабильный ключ из значений записи, что предотвращает повторную загрузку идентичных изменений. Полностью идентичные строки считаются одной записью: если это разные пары, в Excel необходимо заполнить «Пара до».
- Записи, не сопоставленные с действующим расписанием, остаются в substitutions с флагами importUnresolved / pendingForReplacement.
- Такие записи показаны в разделе расписания «Неназначенные отмены / пары для будущей замены» и в разделе «Замены» с полной хронологией (без ограничения последними 100).
- Эти записи пока не являются занятиями в сетке: до сопоставления/назначения они не блокируют время аудитории и не включаются в отчет фактических часов.
- После импорта изменения следует сохранить в системе. Перед применением на рабочем сервере проверьте импорт на резервной копии.
