# Изменения от 22.10.2026

- На странице «Замены / отмены / переносы» блок «Неназначенные занятия и переносы» перенесён под основную таблицу пар.
- Замены подсвечивают только ячейку, в которой изменились номер пары, преподаватель или аудитория; прежнее значение сохраняется под новым. Отменённые пары сохраняют отдельную красную маркировку.
- Редактор мероприятий дополнен типом «Пара для заочников». Можно вписать свободное название группы, которой нет в справочнике; выбрать преподавателей из базы, аудиторию, неделю, день, время и название дисциплины. Такие записи показываются у преподавателя и по аудитории. Они являются отдельными записями расписания, не создают автоматически учебную нагрузку и не прибавляют фактические часы.

Перед промышленным развёртыванием проверить сценарии на копии данных и выполнить сборку frontend (`npm install && npm run build`).
