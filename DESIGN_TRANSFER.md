# Перенос дизайна из timetable22-main-2

- Публичный интерфейс и компоненты Vue, шрифты, палитра и оформление перенесены из второго архива.
- Полный редактор расписания из первого архива на React сохранён; адрес `/admin` открывает его, а не упрощённый макет.
- `app.py` и серверные модули первого архива не заменялись.
- `App.jsx`, `storage.js`, `auth.js`, `editorTransport.js` оставлены из первого архива.
- Входная точка Vite выбирает Vue для публичных маршрутов и React для `/admin`.
- Для установки: `cd frontend && npm ci && npm run build`.
