# Отчёт о переносе проверок — 06.11.2026

**Исходные файлы:** `timetable22-main.zip` (версия 1896) и `time-main(2).zip` (версия 1895).

## Изменения

Добавлена только папка `tests/` и этот отчёт; исходный код приложения, API, планировщика, загрузки, авторизации, package.json и Docker-конфигурация не изменялись.

- `tests/regression/` — 14 проверок, совместимых с текущей семантикой приложения. Старые жёсткие проверки номера сборки сняты, содержательные проверки оставлены.
- `tests/legacy_reference/` — полный набор исходных проверок в качестве справочного материала. **Не исполнять автоматически**: исторические проверки могут противоречить текущей архитектуре. В частности, ранние требования автоматически переносить нагрузку из другой группы по одной только связи потока являются устаревшими.
- `tests/run_regression.py` — запуск набора проверок из одного места, не требует установки дополнительных npm-пакетов.
- `tests/bench_lookup.mjs` — синтетический бенчмарк алгоритма индексированного поиска.

## Прогон

Команда: `python tests/run_regression.py`.

**23/23 успешно**: 14 адаптированных проверок из старой версии, 3 клиентских smoke-проверки, 5 проверок планировщика/звонков/слотов и 1 синтетический бенчмарк.

Бенчмарк показывает преимущество индексированного метода перед линейным на синтетических данных (зависит от нагрузки машины); **это не результат сравнения скорости работы двух собранных сайтов и не гарантия времени загрузки страницы**.

## Ограничения

- Flask отсутствует в тестовой среде; установить его не удалось из-за отсутствия доступа к PyPI. Python-интеграционные сценарии авторизации и редактора не считались пройденными.
- Полный браузерный e2e, сборка Vite с npm-зависимостями, многопользовательское тестирование на реальном сервере и нагрузочное тестирование PostgreSQL не проводились.
- Отдельные старые тесты сравнивают новые функции с отменённой исторической логикой. Они оставлены в архиве для ревью, без скрытого изменения производственных функций.

**Вывод:** набор регрессионных проверок безопасно добавлен в первую версию. Новых зависимостей и постоянных обработчиков или фоновых проверок в приложении нет. Для разрешения публикации на сервере дополнительно требуется прогон Flask интеграции и браузерных сценариев в окружении с зависимостями.
