# Экскурсия вместо пары — уточнение 21.10.2026

В заменах на дату выберите пару и нажмите «Заменить» → «🚌 Отменить пару + экскурсия».

Операция хранится как единая датированная запись `type: "excursion"` с двумя независимыми последствиями: исходная учебная пара считается отменённой (включая учёт нагрузки и освобождение аудитории); в публичной карточке группы выводится блок «Мероприятие: Экскурсия» без кабинета и без преподавателя. Исходное постоянное расписание остаётся неизменным. Название/место можно изменить в строке замены; крестик снимает операцию. Для другой группы повторите операцию отдельно, если это не единый потоковый экземпляр.

Примечание: экскурсия создаётся именно из записи замены, а не в виде отдельного редактируемого объекта в общем разделе «Мероприятия». Поэтому её редактирование и удаление выполняется в заменах. Если нужен единый объект мероприятия для нескольких групп, используйте существующий редактор мероприятий.
